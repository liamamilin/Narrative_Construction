# 叙事构造（Narrative Construction）

**定义现实，识别剧本，塑造行动** · *Lin Mi*

一本关于“命名权、解释权、十三个核心叙事容器与行动剧本”的系统化实战书籍：拆解人如何通过“事实形态 → 叙事形态 → 容器 → 定义 → 剧本”理解世界，并在个人、关系与共同体场景中检验、重构与建立自己的话语体系。

## 全书结构

- **导论**（Ch 01–03）：人并不直接生活在事实中、命名权与解释权、定义天然携带剧本
- **第一部分 · 基础框架**（Ch 04–09）：叙事构造、事实与叙事形态、容器/定义/剧本、十三个核心容器、容器关系、定义质量
- **第二部分 · 掌握与生成定义**（Ch 10–11）：定义的结构与掌握、新定义如何生成
- **第三部分 · 十三个核心叙事定义体系**（Ch 12–24）：主体、时间、处境、行为、结果、原因、动机、意图、目标、责任、价值、意义、方向
- **第四部分 · 在现实中使用叙事构造**（Ch 25–34）：从零构造到成为现实的定义者
- **附录 A–H**：容器总表、定义索引、辨析表、剧本对应表与实战审查模板
