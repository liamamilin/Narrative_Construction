# Theory Baseline：叙事构造理论单一事实源

> 本书所有章节、附录和模板都必须遵守本文件定义的理论基线。

## 1. 十三个容器的三种类型

十三容器虽然都称为"容器"，但分属三种不同的类型。每类容器的现实基础和叙事工作不同，不得强制使用相同的"现实依据—叙事定义"结构。

### 1.1 事件材料容器

处理：**实际存在或发生了什么。**

| 容器 | 核心问题 | 现实基础 | 叙事中的工作 |
|------|----------|----------|-------------|
| 主体 Subject | 谁？ | 可观察或可确认的个人/群体/组织 | 命名与定性——把这个主体定义成什么角色 |
| 时间 Time | 什么时候？ | 可测量的日期、时长、时间点 | 命名与定性——把这个阶段定义成什么性质 |
| 处境 Situation | 什么局面？ | 可描述的资源、限制、环境参数 | 命名与定性——把这些条件定义成什么局面 |
| 行为 Action | 做了什么？ | 可观察或可记录的动作序列 | 命名与定性——把这个行为定义成什么性质 |
| 结果 Outcome | 什么后果？ | 可观察或可测量的状态变化 | 命名与定性——把这个状态定义成什么性质 |

### 1.2 解释归因容器

处理：**为什么发生，主体想做什么。**

| 容器 | 核心问题 | 现实基础 | 叙事中的工作 |
|------|----------|----------|-------------|
| 原因 Cause | 为什么会发生？ | 潜在机制与条件组合（无法直接观察） | 推断与归因——从证据中构建因果模型 |
| 动机 Motive | 什么内部力量推动主体？ | 心理状态（无法直接观察） | 推断与归因——从行为模式推断驱动力量 |
| 意图 Intention | 主体准备做什么？ | 心理计划（无法直接观察） | 推断与归因——从行为和环境推断行动计划 |
| 目标 Goal | 主体希望实现什么？ | 心理期待（无法直接观察） | 推断与归因——从行为和结果推断追求状态 |

### 1.3 判断方向容器

处理：**应当如何评价，以及接下来怎么办。**

| 容器 | 核心问题 | 现实基础 | 叙事中的工作 |
|------|----------|----------|-------------|
| 责任 Responsibility | 谁应当负责？ | 行为、原因、权力与制度关系 | 评价与选择——基于事实和规则分配责任 |
| 价值 Value | 这是好是坏？ | 事实、价值标准与评价体系 | 评价与选择——基于标准和事实做价值判断 |
| 意义 Meaning | 这说明了什么？ | 事件在更大脉络中的位置 | 评价与选择——把事件嵌入更大的叙事框架 |
| 方向 Direction | 接下来怎么办？ | 事实、标准、目标与行动条件 | 评价与选择——基于多维分析决定行动指向 |

### 1.4 三类容器的根本差异

| 维度 | 事件材料容器 | 解释归因容器 | 判断方向容器 |
|------|-------------|-------------|-------------|
| 证据方式 | 观察、记录、测量 | 推断、模式识别、证据链 | 多来源综合 + 价值立场 |
| 确认程度 | 较高（可独立验证） | 中等（建立在证据上的推断） | 较低（依赖标准和立场） |
| 竞争定义性质 | 不同命名和定性 | 不同因果模型或心理解释 | 不同价值判断或方向选择 |
| 错误典型 | 命名偏离事实 | 把推断当作已确认的事实 | 把价值判断当作事实描述 |

## 2. 相邻容器边界表

以下是在写作中容易混淆的相邻容器对，每对必须保持区分：

### 2.1 动机 vs 意图

| | 动机 Motive | 意图 Intention |
|---|---|---|
| 核心 | 为什么想做（驱动力） | 准备做什么（行动方向） |
| 意识层 | 可潜意识，不一定被主体明确意识到 | 在意识层面，主体知道自己准备做什么 |
| 典型例子 | "他因为愤怒（动机）而骂人" | "他打算（意图）在会上公开质疑这个方案" |
| 禁止 | 不得将动机写为意图，也不得将意图写为动机 |

### 2.2 意图 vs 目标

| | 意图 Intention | 目标 Goal |
|---|---|---|
| 核心 | 准备做什么 | 希望最终实现什么状态 |
| 抽象度 | 接近行动（"我打算和他谈一次"） | 指向结果状态（"我希望关系得到改善"） |
| 典型例子 | "我打算约他出来见面"（意图） | "我希望恢复我们之间的信任"（目标） |
| 禁止 | 不得将具体行动计划（意图）写成最终期望状态（目标） |

### 2.3 目标 vs 结果

| | 目标 Goal | 结果 Outcome |
|---|---|---|
| 核心 | 希望实现的状态（未来） | 实际产生的状态（已完成） |
| 时间 | 行动之前设定的预期 | 行动之后产生的后果 |
| 关系 | 目标与结果可能一致，也可能背离 | |
| 禁止 | 不得把结果倒写为目标（"结果显示他本来就是想……"） |

### 2.4 原因 vs 动机

| | 原因 Cause | 动机 Motive |
|---|---|---|
| 范围 | 包含外部条件、内部因素、结构与历史 | 特指内部驱动力 |
| 例 | "迟到的原因是堵车（外部）+ 起床晚（内部）" | "他坚持这个项目的动机是追求成就感" |
| 禁止 | 不得把动机当作唯一的原因（忽略外部和结构原因） |

### 2.5 意义 vs 价值

| | 价值 Value | 意义 Meaning |
|---|---|---|
| 核心 | 好/坏、正当/不正当的评价 | 在更大脉络中代表什么 |
| 判断类型 | 评价性 | 解释性 |
| 典型 | "这是不公平的"（价值） | "这说明我们的制度需要改革"（意义） |
| 禁止 | 不得把意义写成价值（"这件事的意义是它不好" = 混淆） |

### 2.6 责任 vs 原因

| | 原因 Cause | 责任 Responsibility |
|---|---|---|
| 核心 | 导致结果的条件 | 应当对结果做出回应的主体 |
| 关系 | 有原因不一定有责任（不可抗力） | 有责任不一定有直接因果（监督责任） |
| 禁止 | 不得把"谁造成了这个结果"等同于"谁应当负责" |

## 3. 定义—剧本卡统一结构

每个核心定义在容器章节中展开时，必须使用以下七维剧本卡结构：

### 3.1 剧本卡七维度

| 维度 | 需要回答的问题 |
|------|--------------|
| 角色分配 | 各方被放进什么角色？谁主动谁被动？谁是受益方谁是被损害方？ |
| 关系模式 | 这个定义预设了合作、等级、依赖、竞争还是对抗关系？ |
| 注意焦点 | 这个定义要求人们重点关注什么事实或维度？ |
| 行为许可 | 哪些行为因此变得合理、正当、必须？哪些行为变得不合理、不正当？ |
| 责任分配 | 谁获得什么权利？谁承担什么义务或责任？ |
| 发展路径 | 这个定义预设事情将如何发展？短期路径和长期路径分别是什么？ |
| 结局标准 | 什么会被视为成功、失败、结束、或需继续投入？ |

### 3.2 完整示例："受害者"剧本卡

| 维度 | 内容 |
|------|------|
| 角色分配 | 受害者为遭受损害的一方；存在一个或多个加害方或损害来源；社会/旁观者被期望承担帮助者角色 |
| 关系模式 | 受害方与加害方之间为不对等的损害与被损害关系；受害方与帮助者之间为依赖关系 |
| 注意焦点 | 受害方遭受的损害、加害方的责任、受害方的无辜与被动 |
| 行为许可 | 受害方有权寻求帮助、要求补偿、停止与加害方的合作；帮助者有权介入 |
| 责任分配 | 加害方承担停止损害、道歉、赔偿或接受惩罚的责任；受害方不承担处境的改善责任；社会承担提供救济的责任 |
| 发展路径 | 短期：受害者表达诉求、获得帮助或补偿；中期：可能进入恢复、追责或长期维权；长期：可能修复、固化受害身份或转变为幸存者 |
| 结局标准 | 成功：获得充分补偿、加害方被追责、恢复正常生活；失败：损害持续、追责未果、身份固化 |

## 4. 定义质量的优先级

评价定义质量的八个标准按三层优先级排列。

### 第一层：事实约束（前置条件）

不符合事实约束的定义，无论多么有用或有启发性，都不应采用。

| 标准 | 含义 |
|------|------|
| 事实覆盖度 | 定义是否覆盖了关键事实？有无系统性遗漏？ |
| 准确性 | 定义是否把不同性质的对象区分开？ |
| 边界性 | 知道何时成立、何时不成立？ |
| 可反驳性 | 是否存在可辨认的反例条件？定义是否允许被事实否定？ |

### 第二层：解释质量（在符合事实约束的定义中选择）

| 标准 | 含义 |
|------|------|
| 区分度 | 能否与相近定义区分？ |
| 解释力 | 能否解释相关行为和结果？ |
| 生成力 | 能否帮助预测后续发展？ |

### 第三层：行动价值（在前两层成立后参与选择）

| 标准 | 含义 |
|------|------|
| 行动价值 | 能否改善判断与行动？ |
| 用途 | 在多个同样准确的定义中，选择更有行动价值的 |

### 核心原则

> **先准确，再有用；不能为了有用而牺牲真实。**

## 5. 容器的使用规则

### 5.1 容器是扫描地图，不是强制填表

十三容器应作为叙事分析时的完整扫描清单，但不要求在每次分析中都填满所有容器。

### 5.2 允许的标注状态

对于证据不足的容器，允许标注为：

- 未知（Unknown）
- 暂无法判断（Cannot determine yet）
- 存在多个候选定义（Multiple candidates）
- 当前不重要（Not relevant now）

### 5.3 事实、推断和判断不得混层

- 事件材料容器中的定义 → 以可确认事实为基础，偏离事实即需修正
- 解释归因容器中的定义 → 必须以证据标记，不得写成已确认的事实
- 判断方向容器中的定义 → 必须注明所依据的价值标准和条件

## 6. 本书核心主轴

> **现实对象进入容器，被赋予定义；定义携带剧本；剧本组织判断与行动；面对新现实，人还可以主动生成新的定义。**

本书的所有内容都服务于这一条主轴。任何偏离这一主轴的论述、例子或章节产物都应被审查和修正。
