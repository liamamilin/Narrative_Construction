# 母案例基准（Case Baseline）

> 全书四个贯穿母案例的事实基准。所有章节引用母案例时，必须遵守本文件中的已确认事实和时间线。不得随意修改或新增事实。

---

## 案例一：林远——个人发展

### 核心情境

一名长期投入创作和学习的人收入不稳定，正在判断应该继续、转型、就业还是建立混合生存方式。

### 角色

| 角色 | 基本信息 |
|------|----------|
| 林远 | 28岁，独居，无重大负债。本科中文专业。 |
| 朋友 | 林远的朋友，经营一家小型创业公司。 |
| 父母 | 在二线城市，有退休金，目前不需要林远经济支持。 |

### 时间线（不可修改）

- T=0：林远开始自由撰稿和内容创作
- T+3年：已发表约200篇文章，累计读者约3万人
- T+3年-3个月：收入开始明显下降
- 当前：收到朋友邀请加入创业公司做内容运营

### 已确认事实

1. 过去三年以自由撰稿和内容创作为主要收入来源，年收入税后在8-15万之间波动。
2. 发表约200篇各类文章，累计读者约3万人。
3. 存款约8万元，无房产，无车。
4. 最近三个月收入明显下降（约过去的60%）。
5. 收到朋友邀请：加入小型创业公司做内容运营，月薪1.2万。
6. 林远没有全职工作经验。

### 未知信息（不得虚构）

1. 创作能力是否有持续提升空间？
2. 内容市场是否在持续增长？
3. 朋友的公司是否可靠？
4. 林远的焦虑程度是短期波动还是长期趋势？
5. 林远的真实偏好——他自己也不完全确定。

### 竞争定义基线

| 容器 | 定义A | 定义B | 定义C |
|------|-------|-------|-------|
| 主体 | 坚持理想的创作者 | 逃避稳定就业的自由职业者 | 正在探索阶段的年轻人 |
| 时间 | 窗口期 | 危机期 | 转型期 |
| 处境 | 自由但有风险 | 不稳定且不可持续 | 有选择但需决策 |
| 动机 | 追求创作自由 | 害怕进入职场竞争 | 寻找适合自己的路径 |

### 各章可新增的内容规则

各章可以在竞争定义表中添加新的竞争定义，但不得修改已确认事实、时间线和未知信息。

## 案例二：A 与 B——关系

### 核心情境

一段亲密关系逐渐疏远，一方发来"找时间当面聊清楚"的消息，但双方对当前关系已有不同理解。

### 角色

| 角色 | 基本信息 |
|------|----------|
| A | 发消息方，30岁左右 |
| B | 收消息方，30岁左右 |

### 时间线（不可修改）

- T=0：A和B开始交往
- T+2.5年：双方交往两年半，没有同居
- T+2年3个月：见面频率从每周3-4次降为每周1次
- T+2年4个月：A两次提出想聊聊关系，B以太忙推迟
- 当前：A发消息"我们下周见个面吧，有些事想当面聊清楚"

### 已确认事实

1. A和B交往两年半，没有同居，各自有住处。
2. 最近三个月见面频率从每周3-4次降为每周1次。
3. A最近两次主动提出想聊聊关系，B以"最近太忙"为由推迟。
4. 上周A发消息："我们下周见个面吧，有些事想当面聊清楚。"
5. B看到消息后感到紧张和回避。
6. 没有重大冲突或背叛事件。
7. 双方各自有稳定工作，经济独立。

### 未知信息

1. A真正想聊的具体内容。
2. A对关系的定义（正在疏远、需要修复、还是准备结束）。
3. B对关系的定义。
4. 疏远的具体原因。
5. 双方各自的真实需求和期待。

### 各章可新增内容规则

可新增A或B的行为描述（如见面后的对话内容），但不得改变已确认事实。

## 案例三：白鹭项目——组织

### 核心情境

一个重要项目延期并失去客户信任，管理层准备重组团队，各方对失败原因和责任存在冲突。

### 角色

| 角色 | 基本信息 |
|------|----------|
| 产品经理 | 白鹭项目产品负责人 |
| 项目经理 | 白鹭项目经理 |
| 市场部 | 提出需求变更的部门 |
| CEO | 公司CEO，已要求复盘与重组方案 |
| 客户 | 白鹭项目的客户 |

### 时间线（不可修改）

- T-6个月：白鹭项目启动，预计周期5个月
- T-4个月：两个核心功能被要求重做（市场部需求）
- T-2个月：项目经理请假两周
- T-1个月：两名核心开发者提出离职
- T=0：项目交付，客户极度不满
- T+0：CEO要求一周内提交复盘与重组方案

### 已确认事实

1. 公司约80人，C轮融资后约一年。
2. 项目团队12人。
3. 项目计划5个月，实际8个月交付。
4. 两个核心功能在中途被要求重做（市场部要求）。
5. 项目经理在后半段请假两周。
6. 两名核心开发者提出离职。
7. 客户威胁更换供应商。
8. CEO要求一周内提交复盘与重组方案。

### 未知信息

1. 重做决策是否经过充分评估和沟通。
2. 项目经理病假对进度的实际影响。
3. 客户不满多少来自产品缺陷，多少来自关系管理。
4. CEO重组方案的方向。
5. 公司现金流状况。

### 各章可新增内容规则

可新增具体的数据（如缺陷率40%等）和各方对话内容，但不得与已确认事实矛盾。

## 案例四：临川市——公共事件

### 核心情境

一座虚构城市在经历重大自然灾害后，政府实施了一系列严格的管理措施，引发部分居民的支持、抗议和对抗。

### 时间线

- T-6个月：临川市七级地震
- T-6个月至T-3个月：灾后严格管制
- T-3个月：基本生活秩序逐步恢复，管制措施仍然存在
- 当前：发生抗议活动，政府坚持管制

### 已确认事实

1. 虚构城市临川市，人口约200万。
2. 七级地震，约800人死亡，大量建筑损毁。
3. 灾后政府实施了严格管制（物资配给、人员流动限制、重建区域管制）。
4. 三个月后基本秩序恢复，管制仍然存在。
5. 过去一个月发生了几次小型抗议。
6. 一家独立媒体发布了关于物资采购价格的质疑报道。
7. 其他城市类似灾害后管制时长4至18个月不等。
8. 下一次地方选举在10个月后。

### 未知信息

1. 物资采购是否存在腐败。（报道提出了质疑但证据不完整）
2. 管制延续的真实原因。
3. 抗议者的代表性。
4. 政府对异见的容忍度。
5. 受管制区域内居民的真实态度。

### 各章可新增内容规则

各章可以细化场景（如某次具体抗议的规模、政府的公开声明内容），但不得改变已确认事实。
