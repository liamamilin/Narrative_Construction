## Terminology

| Chinese | English | Abbrev | Notes |
|---|---|---|---|
| 叙事构造 | Narrative Construction | NC | 围绕核心对象形成定义，并由这些定义组织对现实的理解与行动 |
| 叙事 | Narrative | | 对主体、事件及其意义形成的整体说法 |
| 叙事对象 | Narrative Object | | 叙事需要定义和处理的对象 |
| 叙事容器 | Narrative Container | | 用于承载某一类叙事定义的基本位置 |
| 定义 | Definition | | 对某个对象作出的具体识别、命名与边界划分 |
| 叙事定义 | Narrative Definition | | 基础对象在叙事中被理解和表达成的形态 |
| 现实依据 | Reality Basis | | 对象在现实中存在或可被指认的基础 |
| 叙事定义 | Narrative Definition | | 对象被定义、解释和理解成的样子 |
| 剧本 | Script | | 某种定义预设的角色关系、行为期待、发展路径与可能结果 |
| 话语体系 | Discourse System | | 个人或共同体稳定使用的一组概念、定义、判断和表达方式 |
| 竞争定义 | Competing Definitions | | 针对同一对象提出、彼此争夺解释权的不同定义 |
| 定义生成 | Definition Generation | | 从事实特征和核心机制中形成新定义的能力 |
| 命名权 | Naming Power | | 决定一个对象被称为什么的权力 |
| 解释权 | Interpretive Power | | 决定对象或事件应当如何被理解的权力 |
