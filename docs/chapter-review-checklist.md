# 每章一致性审查表

每章完成后，逐项检查以下问题。

## 事实与推断

- [ ] 是否混淆了可确认的事实与推断？（事件材料容器中的定义是否有事实支撑？）
- [ ] 解释归因容器中的定义是否标注了证据状态？（"依据当前行为推测" 而非 "他一定是"）
- [ ] 判断方向容器中的定义是否说明了依据的价值标准？

## 容器使用

- [ ] 是否把容器写成了线性过程？
- [ ] 是否强制填满了所有容器？（允许标注"未知"、"暂无法判断"）
- [ ] 动机、意图、目标是否区分清楚？
- [ ] 目标与结果是否区分清楚？
- [ ] 意义与价值是否区分清楚？
- [ ] 原因与责任是否区分清楚？
- [ ] 原因与动机是否区分清楚？

## 定义质量

- [ ] 定义是否连接了可确认的事实特征？
- [ ] 是否使用标签或评价替代了真正的定义？
- [ ] 是否把行动价值置于事实准确性之前？

## 剧本分析

- [ ] 剧本是否至少覆盖了七维剧本卡中的 4 个以上维度？
- [ ] 剧本是否超越了"危机→紧急行动"级别的过于简化的表述？
- [ ] 是否说明了定义突出什么事实、遮蔽什么事实？

## 案例使用

- [ ] 案例是否使用了四个贯穿母案例之一？（或说明了切换理由）
- [ ] 案例是否完整展示了从事实到定义到剧本到行动的链条？
- [ ] 案例事实是否与 book-mother-cases.md 保持一致？

## 章节结构

- [ ] 容器章节是否覆盖了全部十项模板要素？
- [ ] 应用章节是否聚焦了该章特有的真实难点？
- [ ] 结论章节是否遵守了独立的结构（区别于容器模板）？

## 全书一致性

- [ ] 术语是否与 theory-baseline.md 一致？
- [ ] 是否有任何内容与 theory-baseline.md 冲突？
- [ ] 是否有任何内容与其他章节重复或矛盾？
